# Denys Finite State Machine (FSM)

A Godot Engine addon with a basic, simple implementation of the Finite State Machine (FSM) design pattern. This implementation includes:

- A Base script for the state machine as a node
- A Basic abstract implementation for a state class
- Both classes have an icon for the node instances

## Documentation

To find information about the app or check the [documentation](./docs/index.md) you can go to the Documentation section.

Currently the addon is made for Godot Engine v4.7+. Any compatibility change may be noted in the Changelog part of the Docs
